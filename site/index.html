k15 turns a folder of static files into a bootable x86-64 HTTPS image: boot sector, virtio-net, ARP, TCP, TLS 1.3 and HTTP in 13,859 bytes of assembly, with the files behind it. There is no Linux on the disk, no kernel, no shell, no file system, no login, and no executable data pages; any CPU fault resets the machine back into k15.
